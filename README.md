terms-of-service agreement. This entry's program writes one deadpan clause
to `/output/entry.txt`:

> Section 12.3: the User grants the Company a perpetual, royalty-free
> license to the User's dreams, including the right to sublicense any
> recurring nightmare to the highest bidder.
